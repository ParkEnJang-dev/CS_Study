## 학습 방법

```
1시간 루틴:
├── 00~20분  1번 문항 — 개념 학습 + 노트 정리
├── 20~40분  2번 문항 — 개념 학습 + 노트 정리
├── 40~55분  3번 문항 — 개념 학습 + 노트 정리
└── 55~60분  3문항 소리 내어 답변 연습 (각 1분씩)
```

**채점 기준** (각 문항에 O/△/X 기록):

| 등급 | 기준 | 후속 |
|:----:|------|------|
| **O** | 2분 이상 막힘 없이 설명 가능 | 다음으로 |
| **△** | 대략 알지만 꼬리질문 오면 막힘 | 복습일에 재시험 |
| **X** | 핵심을 못 짚음 | 다음날 복습 + 복습일에 재시험 |
